# 在线小说源 · 界面设计说明

- 对应功能：爱丽丝书屋在线书源（可行性见 [在线小说源-爱丽丝书屋-可行性.md](在线小说源-爱丽丝书屋-可行性.md)）
- 设计基线：DSO UI（`docs/DSO-UI.md`）+ 现有漫画/短剧页面已建立的交互习惯
- 状态：**设计说明 + 静态稿**（三帧见 `design/novel-online/`；未改业务代码）

## 1. 设计主张

**一个阅读器，两个货架。**

在线源不做一个"内置浏览器"，也不复刻站点首页（推荐位、广告位、评论一律不搬）。站点只承担"供货"：搜书、给书目、给正文。读的方式与本地 txt 完全一致——同一套阅读器、同一套排版偏好、同一套进度记录。

但"书从哪来"必须永远可回答：`我的书架`（在线）与 `本地索引`（本地）互不写入，同一本书两边都能到，靠详情页的「本地已有」条把关系讲明。合流看起来更省事，代价是用户再也分不清自己读到的是缓存还是原文件。

界面上的来源痕迹只出现在三处：左栏的「在线」书源卡、书卡的「✓ 本地」角标、详情页的本地条。其余一切照旧。

## 2. 信息架构

顶栏胶囊「本地小说」改为「小说」（本地只是它的一种来源，胶囊名不该比内容窄）。

左栏（`novel.*` 段）在现有「本地索引 / 阅读历史 / 索引设置」基础上重组：

```
书源        [ 爱丽丝书屋 ● 在线 ▾ ]     ← 与漫画源同款式；单选，仅一个源时仍保留位置
发现
  ⌕ 搜索
  ▤ 分类
  ▥ 排行
书架
  ▣ 我的书架        ← 只放用户主动收藏的在线书（不与本地索引合并）
  ▤ 本地索引        ← 既有本地 txt 索引，保持独立
  ▤ 阅读历史
工具
  ⚙ 阅读设置        ← 复用 SettingsDialog「小说」页，不新建页
```

路由（沿用现有命名风格）：

| 路由 | 页面 |
| --- | --- |
| `novel.search` | 在线搜索 |
| `novel.category` | 分类浏览 |
| `novel.rank` | 排行 |
| `novel.book.{sourceId}.{novelId}` | 书籍详情 + 目录 |
| `novel.bookshelf` | 我的书架（仅在线收藏） |
| `novel.history` | 阅读历史 |
| `novel.reader` | 阅读器（既有路由，增加在线态） |

## 3. 三个关键屏

### 3.1 搜索页

```
┌ 左栏 ─┬──────────────────────────────────────────────────────────────────────┐
│       │ ┌──────────────────────────────────────────────────────────────────┐ │
│       │ │ ⌕ 输入书名 / 作者 / 标签            ▦──●──  3 个/行   [ 搜索 ]   │ │
│       │ └──────────────────────────────────────────────────────────────────┘ │
│       │ (全部) (书名) (作者) (标签)                          相关度 ▾          │
│       │                                                                      │
│       │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐                             │
│       │  │ 封面 │ │     │ │     │ │     │ │     │   3:4 卡片；右上状态，右下「本地」│
│       │  └─────┘ └─────┘ └─────┘ └─────┘ └─────┘                             │
│       │   书名     书名    书名    书名    书名     ← 2 行截断，13.5px/600     │
│       │   作者     作者    作者    作者    作者     ← 1 行，11px 次级灰       │
│       │                                                                      │
│       │                    ‹ 上一页   1 / 12   下一页 ›                       │
└───────┴──────────────────────────────────────────────────────────────────────┘
```

- 搜索栏直接复用 `BrowserToolbar`（水印、密度滑杆、搜索按钮、回车提交都在里面）。
- 范围 chips（全部/书名/作者/标签）对应站点的 `f=_all/title/author/tag`；默认「全部」，右键不需要。
- 排序默认「相关度」，另给「最近更新」「字数」——站点 `sort` 参数有限，先只暴露站点真支持的两项，不做假排序。
- 分页沿用 `PagingPanel`（上一页/页码/下一页），不做无限滚动：站点是服务端分页，无限滚动会掩盖"第几页"这个事实。

### 3.2 书籍详情 + 目录

```
┌ 左栏 ─┬──────────────────────────────────────────────────────────────────────┐
│       │ ← 返回搜索                                                            │
│       │ ┌────────┐  书名（19px / 600，最多 2 行）                              │
│       │ │  封面   │  作者 · 已完结 · 11 章 · 12.1 万字                            │
│       │ │ 168×224 │  #乱伦  #人妻  #母子          ← 中性药丸，不给标签上色       │
│       │ │        │  简介三行……                                    展开 ∧        │
│       │ └────────┘  [ 继续阅读 · 第 9 章 ]   [ 加入书架 ]   [ 导出 TXT ]         │
│       │ ────────────────────────────────────────────────────────────────────  │
│       │  目录   共 11 章 · 已读 9                       [倒序 ⇅]  [跳到最新]     │
│       │ ┌──────────────────────────────────────────────────────────────────┐  │
│       │ │ 序章                                              2025-06-07      │  │
│       │ │ 第一章 家中训练                                    2025-06-07  ✓   │  │
│       │ │ 第二章 禁忌的赛前日常训练（下）                     2025-06-07  ✓   │  │
│       │ │ …（虚拟化列表，千章级不掉帧）                                       │  │
│       │ └──────────────────────────────────────────────────────────────────┘  │
└───────┴──────────────────────────────────────────────────────────────────────┘
```

- **整页而不是右侧抽屉**。理由：简介要能展开、目录动辄上千行，抽屉宽 620 也要抢走列表的横向空间；而目录是这本"书"的主内容，不是列表的附属信息。
- **主操作只有一个**：实心按钮「继续阅读 · 第 N 章」（无进度时是「开始阅读 · 第 1 章」），用 `PrimaryBrush`。`NovelAccentBrush` 只出现在「小」徽标与阅读进度细条上——类型色不抢主操作的活。
- 已读章节行尾给一个 `✓`（`TextDisabledBrush`）而不是整行变色；目录行有 hover 填充（`HoverBgBrush`），点击即进阅读器并从该章第一页开始。
- 章节目录超过 200 章时，标题栏右侧出现书内搜索框（就地过滤，不发请求）。

### 3.3 阅读器（在线态）

```
┌ ← 返回 │ 书名 · 第 9 / 11 章                    ⌗ 目录   Aa   ◐ 背景        ┐
│                                                                          │
│      　　第九章　实践班与进修班                                           │
│      　　正文……（沿用现有阅读区：分页 / 滚动、背景、字号、行高、缩进）      │
│                                                                          │
│ ──────────────────────────────────────────────────────────────────────── │
│  ‹ 上一章                3 / 12 页 · 本章 38%                下一章 ›     │
└──────────────────────────────────────────────────────────────────────────┘
```

- 阅读区**一个像素都不改**。这是这个功能最重要的克制：在线书不该有一套不同的阅读体验。
- 顶部标题从"文件名"变成"书名 · 第 N / M 章"；底部页码仍是章内页码，右侧补一个"本章 38%"。
- 目录做成右侧抽屉（宽 320，滑入 180ms），当前章高亮 + 自动滚到可见；点章直接切，不返回详情页。
- 章节加载：旧章保持可见，顶部一条 2px `NovelAccentBrush` 进度条；成功则 120ms 交叉淡入；失败在底部出内联条「这章没取到 · 重试 / 下一章」，不弹模态框。
- 离线：已缓存章节正常读；未缓存的点开给「当前离线，已缓存的 3 章可以继续读」。

## 4. 本地优先规则

在线页只是"找书"的入口，一旦这本书本地已经存在（刮削/导出过），**在线页就用本地数据**，不另起一套阅读状态。

| 位置 | 命中本地时 |
| --- | --- |
| 搜索卡片 | 右下角挂「✓ 本地」；书名、字数、封面取本地值，位置仍在站点排序里 |
| 详情页 | 主按钮下出现「✓ 本地已有 · D:\小说\…\书名.txt」条；主按钮改为读本地文件；条右侧留「改用在线数据」 |
| 导出 TXT | 按钮旁说明改为「导出将覆盖同名本地文件」，不静默覆盖 |
| 章节列表 | 表头标注「本地 N 章」；本地解析出的章节优先，站点章节只用于比对缺失 |

匹配规则必须先严后宽：`书名（去括号/别名）+ 作者` 全等 → 命中；仅书名全等 → 标「可能是这本」，不自动接管。宁可多问一次，不做错误关联。

`我的书架` 只收用户主动收藏的在线书，和 `本地索引` 互不写入——不合并，是为了让"这本书来自哪里"永远可回答。

## 5. 状态清单

| 状态 | 表现 | 文案 |
| --- | --- | --- |
| 加载 | 6 张骨架卡（`SkeletonBrush`），不转圈 | — |
| 空结果 | `StateHostControl` 空态 + 两个建议动作 | 没有找到「关键词」／换个书名或作者再试，也可以按标签浏览 |
| 站点不可达 | 错误态 + 重试 | 书源暂时连不上／站点可能换了地址，检查网络后重试，或在设置里换线路 |
| 章节失败 | 阅读器内联条 | 这章没取到　[重试] [下一章] |
| 离线 | 详情页顶部细条 | 当前离线 · 已缓存 3 章可读 |
| 已读 | 目录行 `✓`、卡片 2px 进度条 | — |

不出现「示例」「示意图」「按钮未接入」这类制作说明；在线源的"未接入"只在设置页以开关形式表达（默认关闭，见下）。

## 6. 动效（三处，够用即止）

1. **结果入场**：卡片 12ms 交错、上移 4px 淡入，总时长上限 200ms；超过 12 张不做交错，整批淡入。
2. **章节切换**：旧章 120ms 淡出 → 新章 120ms 淡入，与顶部进度条同时结束，避免闪白。
3. **目录抽屉**：右侧 180ms `cubic-bezier(0.2,0,0,1)` 滑入，遮罩 12% 黑，`Esc` 关闭。

全部读 `SystemParameters.ClientAreaAnimation`，系统关了动效就直接切。

## 8. 复用与新增

**直接复用**：`BrowserToolbar`、`StateHostControl`、`VirtualizedCardGrid`、`MediaResultHost`、`MediaCard`（`NovelCardAdapter` 已存在，补 author/status 两个字段）、`PagingPanel`、`GhostButtonStyle`、`KindBadgeBorderStyle`、`NovelProgressFillStyle`。

**新增**：
- `NovelSourceSelector`（左栏顶部，沿用漫画源 ComboBox 样式，项内带"在线"小点）
- `ChapterListPanel`（虚拟化章节列表，支持千章 + 已读标记 + 就地过滤）
- `ReaderChapterDrawer`（阅读器右侧目录抽屉）
- `NovelBookView`（详情页）

**设置页增量**（SettingsDialog「小说」页末尾，不新建页）：启用在线书库（默认开）、专用代理。

## 9. 刻意不做

- 不做站点首页复刻（推荐位、排行榜大图、广告位、评论区）。
- 不做站点登录、书架同步、点赞投币。
- 不做书架合流：`我的书架`（在线）与 `本地索引`（本地）互不写入；同一本书的"我已下载"状态通过详情页的「本地已有」条表达，不靠合并列表。
- 不做阅读器主题/排版的新选项：现有 6 种背景 + 字号/行高/缩进已经够，在线书没有理由特殊。

## 10. 已定的三个取舍

1. **详情页走整页**，不用右侧抽屉：简介要能展开、目录上千行，抽屉会同时挤掉列表和目录。
2. **书架不合并**；本地已有则在线页优先用本地数据（规则见第 4 节）。
3. **导出 TXT 进第一版**，放详情页次按钮位；本地已有时改为覆盖并明确提示。

**与稿子的差别（有意为之）**：

1. 卡片角标是深色玻璃 chip（`#8C0B0E14`）——WPF 没有背景模糊，用不透明度换同样的克制。
2. 搜索页没有「相关度 / 最近更新」排序下拉：站点的搜索 `sort` 参数没有验证过，不暴露假控件；分类页的排序是站点真支持的 `order` 参数，所以有。
3. 分类 / 排行页是表格（序号、书名、作者、字数、更新时间、人气），不是卡片网格：站点这两页本身就是表格，一屏能看 12 行，比卡片更适合"扫一遍找书"。
4. 阅读器的章节标题作为正文首行左对齐显示——现有阅读器是单个 TextBlock，没有段落模型，居中单行需要改阅读器结构，暂不做。
5. 详情页头用了现有的 `CardPanelStyle` 卡片，而不是通栏白底：与漫画详情页同一套骨架，切换类型时视觉不断层。

真实 WPF 渲染的七帧（1440×900，离线假数据）在 `design/novel-online/shots/wpf-*.png`：
`online-search` / `book` / `reader` / `category` / `rank` / `shelf` / `history`。
